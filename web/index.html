FireRed QoL Player

Insert your cartridge

Pick the .gba file you built from this repo. It stays on this device: nothing is uploaded.

In-game QoL controls

  • L toggles auto-run (hold B to walk)
  • R starts a DexNav search once a species is registered
  • Register EXP. SHARE to SELECT to toggle it fast

Keyboard (default)

  • ←↑→↓ D-pad · X A · Z B
  • Enter Start · V Select · Q L · E R
  • Remap under the gear menu → Controls. Phones get on-screen buttons.

Install as an app

  • iPhone/iPad: Safari → Share → Add to Home Screen.
  • Android or desktop Chrome/Edge: menu → Install app.
  • After the first visit it also works offline.

Saves

  • Your in-game save lives in this browser, under one fixed name, so it carries over when you load a newer build.
  • Clearing site data erases it. Use Export save now and then.
